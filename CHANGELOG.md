## [0.1.4] - 2026-11-27

### Added
- **10 Battlefield Audit & Enterprise GitOps Guardrails (Cohorts 01–04)**:
  - **Trap 1: Flow-Style Mapping Guard (`typo_healer.rs`)**: Preserves inline flow-style environment variables and port mappings (`- { name: PYTHONPATH, value: "..." }`).
  - **Trap 2: OpenShift Template Protection (`typo_dictionaries.rs`)**: Protects OpenShift `Template` root key `objects:` from false-positive coercion to `subjects:`.
  - **Trap 3: GA Service Specification Properties (`typo_dictionaries.rs`)**: Registered `internalTrafficPolicy`, `allocateLoadBalancerNodePorts`, `loadBalancerClass`, and `trafficDistribution` in `SERVICE_SPEC_KEYS`.
  - **Trap 4: Argo Events & Custom Scope Isolation (`typo_healer.rs`)**: Isolated `SERVICE_REFERENCE_KEYS` strictly to standard Ingress/Webhook paths; protected `ports: []` arrays from singular coercion.
  - **Trap 5: Service Port Item Protection (`typo_healer.rs`)**: Protected singular `port` inside service port items from singular/plural distortion.
  - **Trap 6: Scorecard Key Protection (`typo_healer.rs`)**: Protected Scorecard `stages:` from coercion to `status:`.
  - **Trap 7: Helm Template Indentation Preservation (`template_masker.rs`)**: Standalone Helm control lines (`{{- if ...}}`) preserve exact leading indentation, preventing premature block scalar termination.
  - **Trap 8: Remediation Token Unmasking (`cli/heal_cmd.rs`)**: Applied `unmask_template_expressions` on all remediation strings, preventing `__YAMLR_TPL_VAL_` leaks.
  - **Trap 9: POSIX Octal Sanitization (`storage_ops_healer.rs`)**: Restricts `STO-008` to quoted string literals (`"0755"`), leaving unquoted POSIX octal (`0555`, `0755`) intact to preserve human readability.
  - **Trap 10: Kustomize Patch Delta Detection (`job_contract_healer.rs`)**: Recognized partial Job podSpecs without `containers` as strategic merge patch deltas, skipping unwanted `restartPolicy` injection.
- **Enterprise Documentation Suite**:
  - `docs/HEALING_RULES.md`: Exhaustive reference of all healing rules, scorecard tiers, triggers, and safety gates.
  - `docs/CLI_REFERENCE.md`: Complete CLI manual covering `scan`, `heal`, `check`, `migrate`, `diagnose`, and exit code contracts.
  - `docs/ARCHITECTURE_MODEL.md`: Full architectural mental model and inter-file connective tissue map.

## [0.1.3] - 2026-11-25

### Added
- **5 Immunity Guardrails against Enterprise & Upstream Pitfalls**:
  - **ApiGroupGuard (`kind_healer.rs`)**: Custom Resource Definitions (CRDs) bearing non-standard API groups (e.g., `stable.example.com/v1`, `CronTab`) are strictly immune from false-positive Kind coercion to core Kubernetes resources (`CronJob`).
  - **GeneratedFileDetector (`cluster_dump_healer.rs`)**: Automated manifests marked with `controller-gen.kubebuilder.io/*`, `operator-sdk`, or `Code generated by ... DO NOT EDIT` are immune from live server-dump metadata stripping (`creationTimestamp: null`), preserving generator contracts.
  - **TemplateConditionalBranchGuard (`pdb_max_unavailable_healer.rs`)**: Unrendered Helm templates with Go template conditionals (`{{- if ... }}`) spanning `minAvailable` and `maxUnavailable` are immune from false-positive mutual-exclusion pruning.
  - **Zero-Behavioral-Mutation Gate (`volume_contract_healer.rs`)**: `hostPath.type: DirectoryOrCreate` injection strictly requires explicit opt-in annotation (`yamlr.dev/hostpath-type: "true"`), preventing unauthorized behavioral changes in production.
  - **BlockScalarVerbatimGuard (`block_scalar_healer.rs`)**: INI and section header lines (e.g., `[SERVICE]`, `[INPUT]`) within literal block scalars are protected from false-positive key interpretation, preserving raw configuration bodies verbatim.


### Added
- **Pre-Write Kubernetes Schema Invariant Gate & Delta Rule V1 \ V0 (cli/schema_gate.rs)**:
  - Closed-struct schema walk against official Kubernetes OpenAPI schemas enforcing semantic invariants (UnknownField, NullForStructure, TypeMismatch, ItemTypeMismatch, EmptySelector, SelectorMismatch).
  - Mathematical Delta Rule (V1 \ V0 = ∅): strictly prevents introducing structural regressions during healing while permitting pre-existing author-defined fields.
  - Per-document stream isolation via stream_document_slices: ensures a syntax error in document 1 does not invalidate baseline schema evaluation for subsequent valid documents.
  - Namespace-safe schema lookup: prevents core Kubernetes schemas from falsely matching external CRD groups (e.g. gateway.networking.k8s.io Gateway vs core Gateway).
  - CLI diagnostic flag yamlr heal --explain-gate <manifest> and configuration controls (schema_gate: off | shadow | enforce).
- **Schema-Guided Indentation Disambiguator (SYN-020, healers/indentation_disambiguator.rs)**:
  - Automatically heals ambiguous tab or off-by-one indentation errors on mapping keys by evaluating legal candidate indent levels against both parser validity and schema invariants.
  - Guarantees zero wrong-fixes: heals if and only if exactly one candidate satisfies the schema contract, failing closed otherwise.
- **Pre-Write Kubernetes Schema Invariant Gate (schemas/unknown_fields.rs, cli/heal_gates.rs)**:
  - Closed-struct map validation against official Kubernetes OpenAPI schemas: recursively walks the AST and flags unrecognized fields under schema-defined structs (e.g. 	argetPort or pp under spec).
  - Pre-write invariant verification in cli/heal_gates.rs guarantees zero 'valid YAML, invalid K8s' mutations ever touch disk.
- **Fail-Closed Semantic Type Gate for Unmutated Files (cli/heal_gates.rs, cli/heal_writer.rs)**:
  - Solves the 'valid YAML, invalid K8s' blind spot: when manifests are syntactically valid YAML but semantically broken (e.g. labels: app:web where a mapping is required), the engine reports fatal schema type mismatches and exits with non-zero exit code 4 instead of falsely exiting 0.
- **Over-Indented Sequence Bullet Parent Isolation (healers/sequence_indent_healer.rs)**:
  - Guards nested list items (nv:, ports:, olumeMounts:) from being mistakenly unindented to match ancestor list bullet prefixes with identical key names (- name:).
- **Zero Wrong-Fix Guarantee on Fault Injection Benchmark**:
  - Verified across all fault categories (tab, glued colon, indent+1, unclosed quote, unclosed flow, CRLF) with 0 wrong fixes, 0 silent failures, and 0 dropped comments.
- **Cross-Resource ConfigMap & Secret Key Reference Alignment (Rule REF-006)**:
  - Detects misspelled `configMapKeyRef.key` and `secretKeyRef.key` references preventing `CreateContainerConfigError` pod startup crashes.
  - Mathematical typo guard: Damerau-Levenshtein distance == 1, length >= 4, identical token count.
  - Strict digit sequence preservation: strictly forbids transposing or altering digits (e.g. `SHARD_12` vs `SHARD_21`).
  - Provider immutability: mutates only consumer workloads; provider ConfigMap/Secret AST is never altered.
  - Structured `.yamlr.yaml` opt-in (`allow-reference-alignment: true`) resolved from repository root; default is S0 explainable advisory.
- **Cross-Resource Ingress Backend Service Port Alignment (Rule NET-020)**:
  - Validates Ingress routing rules against exposed Service port definitions, catching 502/503 Bad Gateway errors.
  - Identifies container `targetPort` vs exposed Service `port` mismatches with clear diagnostic guidance.
  - Internal management port shield: warns against public exposure of administrative endpoints (`actuator`, `metrics`, `debug`, `pprof`).
  - Protocol-swap prohibition: strictly prevents swapping between HTTP/HTTPS, gRPC/gRPCs, or WS/WSS.
  - Safe bypass for `ExternalName` services and synthetic routing annotations (`use-annotation`, `ssl-redirect`).
- **Standalone Kubernetes API Migration Engine (`yamlr migrate`)**:
  - Dedicated preview-first command for modernizing deprecated and retired Kubernetes APIs (`extensions/v1beta1`, `networking.k8s.io/v1beta1`, `policy/v1beta1`).
  - Enforces zero-side-effect mandate: strictly upgrades deprecated API versions without injecting unrequested limits, probes, or security contexts.
  - Supports `--to <VERSION>`, `--diff`, `--apply`, and `--no-backup`.
- **Pre-Write Invariant Verification Gates (`heal_writer.rs`)**:
  - Bounded YAML syntax validation: eliminates infinite loops on invalid original YAML (such as tabs).
  - Non-empty AST check: prevents accidental file truncation.
  - Runtime comment preservation: strictly aborts write if `healed_comments < orig_comments`.
  - ConfigMap/Secret payload immutability: verifies raw data blocks remain 100% byte-for-byte identical.
  - In-memory double-pass idempotency check: ensures mathematical stability (`heal(heal(M)) == heal(M)`) while filtering out non-mutating advisories.
  - Concurrency lock: verifies file was not modified on disk between read and write.
- **In-Toto SLSA v0.2 Provenance Bundles**:
  - Cryptographic attestation generation encapsulating canonical SHA-256 manifest digests and SLSA v0.2 predicate statements (`create_manifest_provenance_bundle`).
- **POSIX Process Exit Code 4**:
  - Dedicated exit code `4` (`EXIT_SYNTAX_ERROR`) for unfixable syntax or invalid original YAML that cannot be safely healed.
- **Default Advisory Mode Visibility**:
  - Surfaced reference advisories across both `yamlr scan` (as CI/CD warnings) and `yamlr heal` (as visible `[ADVISORY]` logs without mutating files).

### Fixed
- **Payload Immutability Gate Block Scalar Preservation**: Fixed false abort (exit 4) where literal block scalars (`|`, `>`) containing `#` lines (e.g. bash scripts in ConfigMaps) were improperly isolated as YAML comments. Block scalars now strictly preserve literal `#` content as continuation shards per YAML 1.2 §8.1.1.
- **Scan Severity Threshold & Text Status Alignment**:
  - `scan --fail-on` now accepts DevOps severity aliases (`high`, `critical`, `medium`, `low`) alongside standard levels (`error`, `warning`, `note`, `info`, `any`, `none`).
  - Terminal scan report outputs `[WARN]` (instead of `[FAIL]`) when findings are below the `--fail-on` threshold, aligning status text with exit code 0.
- **Documentation & Benchmark Truth Alignment**:
  - `docs/GOLDEN_CORPUS_REPORT.md` and `website/docs/GOLDEN_CORPUS_REPORT.md` latency claims aligned with `docs/BENCHMARK_REPORT.md` (marked pending independent multi-environment harness).
  - Documented explicit `<filename>.bak` safety backup suffix for `yamlr migrate --apply` and recommended adding `*.bak` to `.gitignore`.
- **Infinite CPU Hang on Invalid Tabs**: Replaced unbounded iterator in `verify_payload_immutability` with `parse_docs_bounded`.
- **Idempotency Gate Fail-Closed Contract**: Hardened `is_non_mutating_finding` to fail closed by strictly matching verified advisory, notice, auditor, and warning prefixes rather than relying on inverse remediation filtering. Added catalog-wide test verifying that 100% of mutation messages across all 91 healers start with `Remediation [`.
- **Bare UTF-16 BOM Fail-Closed Consistency**: Fixed bare 2-byte BOM payload handling (`transcode_utf16_to_utf8`) to return `None` when content is empty, ensuring `scan` (exit 2), `check` (exit 4), and `heal` (exit 4) all uniformly fail closed on non-manifest byte streams.
- **Cryptographic License Enforcement & Anti-Tamper Hardening**: Sealed the public key root of trust against unauthenticated environment overrides in production and release binaries. `active_license_public_key()` strictly enforces the embedded official public key, rejecting forged enterprise tokens and preventing unauthorized self-minted licensing bypasses.
- **Idempotency Gate Advisory False-Positives**: Pass-2 idempotency check now filters out non-mutating auditor advisories (e.g. mutable image tags).
- **Symlink Target Preservation**: Atomic write logic preserves symlink pointers and writes healed content directly to canonical targets.
- **User Backup File Collision Safety**: Guaranteed preservation of user pre-existing `.bak` files during migration and healing.
