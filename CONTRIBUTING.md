# Contributing to Yamlr Documentation & Ecosystem

Thank you for your interest in contributing to the Yamlr community! We welcome contributions to our documentation, integration examples, diagnostic guidance, and public integrations.

## Code of Conduct
All contributors and maintainers are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Ways to Contribute
1. **Improve Documentation**: Submit improvements to guides, CLI manuals, and diagnostic explanations in docs/.
2. **Report Schema Deviations**: Help us maintain 100% schema accuracy by filing schema reports for edge cases.
3. **Ecosystem Integrations**: Contribute examples for pre-commit hooks, CI/CD runners (GitLab, GitHub Actions, Tekton), and GitOps engines (ArgoCD, Flux).

## Pull Request Guidelines
- Ensure documentation is written in clear, concise technical English.
- Avoid committing any proprietary or confidential credentials, internal IP, or benchmark tokens.
- All code examples in guides must be tested and verified against official Kubernetes schema standards.
